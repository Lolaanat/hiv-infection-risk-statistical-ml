# Dataset

The original notebook expects `AIDS_Classification.csv`.

The source project identifies the dataset as the Kaggle **AIDS Virus Infection Prediction Dataset** with 2,139 observations and 23 variables.

The raw CSV was not included in the provided project materials used to build this repository package, so it is intentionally excluded from the ZIP. Obtain the dataset from its original source and place `AIDS_Classification.csv` in the project root before rerunning the notebook.

Do not commit sensitive or restricted data to a public repository without checking its license and redistribution terms.
